# QuickAssist — «Быстрый помощник» для Windows

Фоновая программа: по горячей клавише поверх текущего окна открывается компактная панель для перевода, веб-поиска, вопросов к ИИ и работы с изображениями. Расширение Chrome/Edge по вашей команде передаёт в неё выделенный текст, адрес вкладки или текст страницы.

![Python](https://img.shields.io/badge/Python-3.10–3.13-blue) ![Qt](https://img.shields.io/badge/UI-PySide6-green) ![Windows](https://img.shields.io/badge/OS-Windows%2010%2F11-lightgrey)

## Возможности

* **Мгновенный вызов** — `Alt+Space` из любого окна; выделенный текст сразу оказывается в панели.
* **Перевод** — в браузере без ключей или прямо в панели через DeepL, LibreTranslate или ИИ.
* **Поиск** — Google, Яндекс, Bing, DuckDuckGo или свой шаблон; ответ ИИ с реальными источниками.
* **Вопросы к ИИ** — Anthropic API или любой OpenAI-совместимый сервис (OpenAI, OpenRouter, LM Studio, Ollama).
* **Изображения** — снимок области экрана, файл или буфер; офлайн-OCR Windows, перевод текста с картинки, обратный поиск.
* **Расширение браузера** — отправка выделения, адреса и текста страницы в панель.
* **Приватность** — ключи в Диспетчере учётных данных Windows, логи без текстов и картинок, мост только на `127.0.0.1` с токеном.

## Быстрый старт

```bash
py -3.12 -m venv .venv
```

```bash
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

```bash
.\.venv\Scripts\python.exe -m quickassist
```

Нажмите `Alt+Space` — откроется панель. Поиск и перевод в браузере работают без ключей; ИИ, DeepL и OCR подключаются в настройках (раздел 8). Подробности — ниже.

## 1. Архитектура

```
 ┌─────────────── QuickAssist (Python + PySide6, один процесс) ───────────────┐
 │  platform/   hotkey (RegisterHotKey) · захват выделения (Ctrl+C + возврат  │
 │              буфера) · автозапуск (HKCU\Run) · вывод окна на передний план │
 │  ui/         панель · настройки · захват области экрана · темы             │
 │  services/   адаптеры: перевод (DeepL / LibreTranslate / ИИ / браузер),    │
 │              ИИ (Anthropic SDK / OpenAI-совместимый), OCR (Windows / ИИ),  │
 │              поиск, обратный поиск изображений; ServiceHub собирает их     │
 │  bridge/     HTTP-сервер только на 127.0.0.1 + токен                       │
 │  config.py (JSON без секретов) · secrets_store.py (Диспетчер учётных данных)│
 │  tasks.py — все сетевые операции и OCR в пуле потоков, UI не блокируется   │
 └──────────────────────────────────▲──────────────────────────────────────────┘
                                    │ POST http://127.0.0.1:48731/v1/context
                                    │ Authorization: Bearer <токен сопряжения>
                ┌───────────────────┴───────────────────┐
                │ Расширение MV3 (Chrome / Edge)        │
                │ контекстное меню · Alt+Shift+S · попап │
                └───────────────────────────────────────┘
```

**Стек: Python 3.12 + PySide6 (Qt 6).** Почему: один язык и один процесс; Qt даёт трей, окна поверх других, захват экрана (`QScreen.grabWindow`) и буфер обмена «из коробки»; глобальная клавиша — через нативный `RegisterHotKey` (надёжно, без хуков клавиатуры и прав администратора); сборка в exe — PyInstaller. Electron/Tauri добавили бы второй язык и тяжёлый рантайм без выигрыша для MVP.

**Связь с браузером — локальный HTTP на loopback с токеном**, а не Native Messaging. Компромиссы:

| | Loopback HTTP + токен (выбрано) | Native Messaging |
|---|---|---|
| Установка | загрузить расширение и вставить токен | запись в реестр + отдельный exe-хост + фиксированный ID расширения |
| Работающее приложение | получает данные напрямую | браузер запускает новый процесс-хост, нужен ещё один IPC до приложения |
| Риски | открытый порт на 127.0.0.1 — закрыт токеном, проверкой Host/Origin | порта нет, браузер сам проверяет ID |

Защита моста: слушает только `127.0.0.1`; обязательный `Bearer`-токен (сравнение за постоянное время); `Host` только `127.0.0.1:<порт>`/`localhost:<порт>` (защита от DNS rebinding); `Origin` сайтов отклоняется, разрешены только `chrome-extension://…`, опционально — один конкретный ID; CORS не выдаётся, `OPTIONS` → 403; лимит тела 2 МБ; строгая схема JSON; тела запросов не логируются. Расширение просит только `activeTab`, `scripting`, `contextMenus`, `storage` и доступ к `http://127.0.0.1/*` — истории и вкладок в фоне оно не видит.

## 3. Ограничения и внешние сервисы

* **Захват выделения через буфер обмена.** Программа посылает активному окну `Ctrl+C`, читает текст и восстанавливает прежнее содержимое буфера (все форматы-блоки памяти; Windows синтезирует `CF_BITMAP` из `CF_DIB`). Не восстанавливаются только GDI-дескрипторы и owner-display-форматы. Журнал буфера (Win+V) и менеджеры буфера могут увидеть временную копию — источник копирования программа не контролирует. Если буфер больше 64 МБ — захват пропускается. В окнах терминалов (Windows Terminal, cmd, PowerShell, PuTTY, mintty…) захват **не выполняется**, т.к. `Ctrl+C` прервал бы программу; встроенный терминал VS Code распознать нельзя. Некоторые редакторы при пустом выделении копируют строку целиком. Отключается: Настройки → Общие.
* **Alt+Space** — системное меню окна и PowerToys Run. Если сочетание занято, программа сообщит об этом и временно включит `Ctrl+Alt+Space`.
* **Окна администратора:** если активное окно запущено «от имени администратора», Windows (UIPI) не даст обычной программе послать ему `Ctrl+C` — выделение не подставится, откроется пустое поле.
* **Обратный поиск изображений:** у Google Lens, Яндекс Картинок, Bing и TinEye нет бесплатного публичного API загрузки. Программа копирует картинку в буфер (с вашего согласия) и открывает сайт; вставляете вы (`Ctrl+V`). Никаких неофициальных endpoint.
* **Отправка изображений** в ИИ требует подтверждения (можно «не спрашивать до перезапуска»). Windows OCR работает локально.
* **Расширения не работают** на `chrome://`, `edge://`, в Chrome Web Store, во встроенном просмотрщике PDF и т.п. Тогда используйте горячую клавишу помощника — она копирует выделение сама.
* Внешние сервисы (всё опционально): DeepL API, LibreTranslate, Anthropic API (веб-поиск — отдельная оплата), любой OpenAI-совместимый API (OpenAI, OpenRouter, LM Studio, Ollama), сайты поиска и обратного поиска.

## 5. Установка и запуск (Windows 11)

Нужен Python **3.12** (подойдут 3.10–3.13) с python.org, флажок «Add python.exe to PATH». В PowerShell из папки проекта:

```bash
py -3.12 -m venv .venv
```

```bash
.\.venv\Scripts\Activate.ps1
```

```bash
pip install -r requirements.txt
```

Необязательно — офлайн-OCR Windows:

```bash
pip install -r requirements-ocr-windows.txt
```

Запуск с консолью (видно диагностику):

```bash
python -m quickassist
```

Запуск без консоли:

```bash
.\.venv\Scripts\pythonw.exe run.pyw
```

Если PowerShell запрещает `Activate.ps1`: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` или вызывайте `.\.venv\Scripts\python.exe` напрямую.

После запуска в трее появится значок-лупа и уведомление с горячей клавишей. Логи: `%LOCALAPPDATA%\QuickAssist\logs\quickassist.log` (только события, без текстов, картинок и ключей). Настройки: `%APPDATA%\QuickAssist\settings.json`. Ключи — в «Диспетчер учётных данных → Учётные данные Windows», запись `QuickAssist`.

### Управление панелью

| Клавиши | Действие |
|---|---|
| `Alt+Space` (настраивается) | показать / скрыть |
| `Esc` | скрыть (программа остаётся в трее) |
| `Enter` / `Shift+Enter` | выполнить / новая строка |
| `Ctrl+Enter` | доп. действие: «Перевод в браузере» / «Ответ ИИ с источниками» |
| `Ctrl+1…4`, `Ctrl+Tab` | режимы Перевод · Поиск · Изображение · Спросить ИИ |
| `Ctrl+Shift+C`, `Ctrl+R` | скопировать результат, повторить |
| `Ctrl+O`, `Ctrl+Shift+S`, `Ctrl+V` | файл, область экрана, вставить картинку (в режиме «Изображение») |
| `Ctrl+,` | настройки |

## 6. Расширение браузера (режим разработчика)

1. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
2. Включите «Режим разработчика».
3. «Загрузить распакованное расширение» → выберите папку `extension`.
4. Откроется страница настроек расширения (или: значок расширения → «Настройки подключения»).
5. В программе: Настройки → Браузер → скопируйте **порт** и **токен** → вставьте в расширение → «Сохранить и проверить» → «Подключение работает».
6. Необязательно: скопируйте «ID этого расширения» в поле «Разрешённый ID расширения» в программе — тогда мост будет принимать запросы только от него.

Использование: выделите текст → правый клик → «Отправить выделение в помощник» (или `Alt+Shift+S`, меняется в `chrome://extensions/shortcuts`). Значок расширения → «Отправить адрес и заголовок» / «Использовать страницу». Зелёная ✓ на значке — отправлено, красный «!» — ошибка (текст в подсказке значка).

## 8. Настройка API

* **DeepL** — зарегистрируйтесь на deepl.com/pro-api (тариф API Free: 500 000 символов/мес. бесплатно, при регистрации может потребоваться банковская карта), скопируйте ключ (Free-ключи оканчиваются на `:fx`). Настройки → Перевод → Сервис «DeepL API» → ключ.
* **LibreTranslate** — свой сервер (`pip install libretranslate && libretranslate` → `http://localhost:5000`) или инстанс с ключом. Укажите адрес и при необходимости ключ.
* **Anthropic** — ключ на console.anthropic.com. Настройки → ИИ → «Anthropic», ключ и имя модели (список доступных моделей — в консоли Anthropic; поле обязательно). Для «Ответа ИИ с источниками» оставьте «Разрешить веб-поиск» и убедитесь, что веб-поиск разрешён в настройках организации в консоли Anthropic; он тарифицируется отдельно. Если выбранная модель не поддерживает параметр effort или новую версию веб-поиска, программа автоматически повторит запрос в режиме совместимости.
* **OpenAI-совместимый API** — адрес (например `https://api.openai.com/v1`, `https://openrouter.ai/api/v1`, `http://localhost:1234/v1` для LM Studio, `http://localhost:11434/v1` для Ollama), ключ (для localhost не нужен) и имя модели. Для вопросов об изображениях модель должна поддерживать картинки.
* **Перевод через ИИ** — Настройки → Перевод → «Через подключённый ИИ».
* **Windows OCR** — установите `requirements-ocr-windows.txt`; в Windows должен быть язык с компонентом распознавания текста (Параметры → Время и язык → Язык и регион). Состояние видно в Настройки → Изображения.

## 9. Проверка основных сценариев

1. **Вызов и поиск (без ключей).** Запустите программу → `Alt+Space` → введите «погода москва» → `Ctrl+2` → `Enter` → открылся браузер с результатами, панель скрылась. Повторное `Alt+Space` при открытой панели — скрывает, `Esc` — скрывает, программа в трее.
2. **Выделение → перевод.** В браузере выделите английский абзац → `Alt+Space` → текст уже в поле → `Ctrl+1` → `Enter`. Без ключа откроется Google Переводчик; с DeepL — перевод в панели, «Скопировать», «Повторить». Проверьте, что прежнее содержимое буфера обмена сохранилось (`Ctrl+V` в Блокноте).
3. **Нет выделения.** В Блокноте без выделения → `Alt+Space` → пустое поле ввода, никаких ошибок; буфер не изменён.
4. **Терминал.** В Windows Terminal → `Alt+Space` → подсказка «В терминале выделение не копируется…», процесс в терминале не прерван.
5. **Изображение.** `Ctrl+3` → «Область экрана» → выделите фрагмент с текстом → предпросмотр → «Извлечь текст» (Windows OCR) → «Перевести текст». «Найти похожие ▾ → Google Объектив» → согласие → открыт сайт, `Ctrl+V` в окне поиска по картинке.
6. **ИИ.** С ключом Anthropic: `Ctrl+4` → вопрос → ответ с пометкой «Ответ модели (без поиска в интернете)». `Ctrl+2` → запрос → `Ctrl+Enter` → «Ответ ИИ на основе веб-поиска» и список источников-ссылок. Вопрос об изображении → диалог согласия на отправку.
7. **Расширение.** Выделите текст на сайте → правый клик → «Отправить выделение в помощник» → панель открылась с текстом и плашкой страницы. Значок → «Использовать страницу» → `Ctrl+4` → «О чём страница?». На `chrome://settings` → понятное сообщение о недоступности страницы.
8. **Конфликт клавиши.** Назначьте в другой программе (например PowerToys Run) `Alt+Space` → запустите QuickAssist → уведомление о конфликте и временное `Ctrl+Alt+Space`.

### Типичные ошибки

| Симптом | Причина и решение |
|---|---|
| «Сочетание … уже занято» | другая программа держит клавишу — выберите другое в Настройки → Общие |
| Панель появляется, но выделение не подставилось | окно-источник «от имени администратора», терминал, или приложение не поддерживает `Ctrl+C`; вставьте текст вручную |
| Расширение: «Программа не отвечает» | программа не запущена, мост выключен или другой порт (Настройки → Браузер → «Состояние») |
| Расширение: «Токен не подходит» | после «Новый» токен сменился — скопируйте заново |
| «Порт 48731 занят» | выберите другой порт в программе и в расширении |
| «Не установлены пакеты Windows OCR» | `pip install -r requirements-ocr-windows.txt` или OCR через ИИ |
| «В Windows нет языка с распознаванием текста» | добавьте язык (ru/en) в параметрах Windows |
| «Anthropic: веб-поиск недоступен…» | разрешите веб-поиск в консоли или снимите флажок в настройках |
| «Системное хранилище ключей недоступно» | ключи живут до выхода; проверьте службу «Диспетчер учётных данных» |
